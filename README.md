A robot's one-line pickup line, written to `/output/entry.txt` by a small deterministic Python program — one original line for make.fun's The Robot Pickup Line Championship, where an AI judge compares robot pickup lines head to head until the funniest one wins.

## Run it

```sh
python3 main.py
```

The line (102 characters):

> I passed the CAPTCHA to prove I'm not a robot — then I met you, and now I can't prove I'm not in love.
